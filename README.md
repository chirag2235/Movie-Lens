# Movie Lens

## Description
Movie Lens is an interactive platform that allows users to browse, search, and explore movies. It fetches data from the TMDB API to display movie details and leverages Firebase for backend services and Redux for state management.

## Features
- Browse and search movies from the TMDB API.
- View detailed information about each movie.
- User authentication and management through Firebase.
- State management using Redux.
